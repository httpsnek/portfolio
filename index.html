My Projects

Estate Shine Cleaning

A marketing and booking website for a premium home cleaning service in Sacramento, CA, built from scratch in vanilla HTML/CSS/JS. Features an interactive SVG floor-plan checklist that shows exactly what gets cleaned room by room, a draggable before/after comparison slider with real client photos, and live online booking through an embedded BookingKoala widget.

HTML CSS JavaScript SVG BookingKoala

Fashion Cutout Bot

A Telegram bot that turns any product photo — a marketplace listing, a photo on a model, a phone snapshot — into a clean transparent PNG of just the garment. A two-stage pipeline (generative extraction + local matting) understands what to cut out, not just how to remove a background, and auto-skips the paid AI step whenever a photo is already studio-clean to keep costs down.

Python aiogram Playwright Gemini API OpenCV

Shop Automation

A Telegram bot that automates product listing for a live shoe & streetwear store on Tilda — from donor photos to a published catalog card. Involved reverse-engineering the undocumented CommerceML sync protocol from scratch and building an idempotent CSV pipeline for the data it can't carry, cutting per-listing work from ~10 manual fields to a couple of Telegram messages.

Python aiogram Playwright CommerceML / XML Cloudflare R2

Maps Hunter

An end-to-end outreach platform that finds local businesses with broken or missing websites via Google Maps, generates a personalized demo redesign for each one, and sends cold outreach with real proof instead of a bare promise — over WhatsApp and CAN-SPAM-compliant email, with a dashboard for manual review before anything goes out.

Python Playwright Flask Cloudflare Pages SQLite

Opora Set

A full B2B/B2C e-commerce platform for a welding & abrasive tools retailer, built from scratch — storefront, admin panel, wholesale approval flow, payments and delivery integration. Includes a bulk supplier-catalog importer that handles messy real-world spreadsheets and forensically recovers product photos embedded as legacy binary objects in old .xls files.

Next.js TypeScript PostgreSQL Prisma LiqPay

GTA RP Server

A commercial GTA Online-style roleplay server for FiveM, built from scratch — infrastructure, deployment, in-game economy, criminal subsystems, and a fair, non-pay-to-win monetization model designed for realistic growth from 0 to 100+ concurrent players. Resources are strictly separated by origin (vendored framework code is never touched directly, custom logic lives in its own layer), and the entire database schema is version-controlled as sequential SQL migrations for a fully reproducible environment.

Lua FiveM / Qbox MariaDB systemd Linux / Hetzner
